## 逐维度分析

### 1. 架构与模块化 — 7.5/10

**保持**: ES Modules 全迁移完成，`window.X` 全局暴露仍为架构债务（HTML onclick 兼容）。页面模块单体化（orders.js 1,387 行）待拆分。

### 2. 代码质量 — 7.5/10 (+0.5)

**提升**: `_applyProfitFields()` 统一利润计算消除 3 处重复。ESLint 0 error / 0 warning（已修复 sourceType + globals）。
**待改进**: orders.js 单体拆分，JSDoc 类型标注。

### 3. 安全性 — 9.0/10 (+0.5) ⭐ 最高分

**提升**: 登录频率限制实现在运行时强制执行（5 次失败/15 分钟锁定）。CSP header 限制 script-src/style-src/connect-src/frame-ancestors。
**保持**: SHA-256 哈希 + 88 处 XSS 全防护 + 时序攻击防护。
**提示**: `CLOUD_SECRET` 部署前需填入真实密钥。

### 4. 测试 — 8.5/10 (+1.0) ⭐ 最大提升

**提升**: exchange.js 达 **100% 全维度覆盖**（+12.5%）。auth.js 新增 10 个锁机制测试。data.js 新增 17 个 Shipments/Invoices 扩展测试。Playwright E2E 框架就绪（6 个登录流程测试）。
**测试总数**: 394 单元测试 + 6 E2E 测试 = **400 测试，全部通过**。

### 5. 错误处理与韧性 — 8.5/10 (+0.5)

**提升**: 全局 `unhandledrejection` 监听器（过滤 AbortError 噪音）。`window.onerror` 边界（排除 SDK 内部错误）。
**保持**: 三层降级（CloudBase→localStorage→空白启动）+ beforeunload 双保险。

### 6. 性能 — 7.0/10

保持: 保存队列合并、轮询跳过窗口、SW 缓存。页面模块仍为一次性全量加载。

### 7. 可维护性 — 7.5/10 (+0.5)

**提升**: 利润计算统一函数降低维护成本。暗色模式 CSS 变量系统从零到完整。ESLint 零 warning 降低噪音。
**待改进**: `DB↔Exchange` 双向依赖，页面模块 HTML 字符串生成器。

### 8. 生产就绪度 — 8.5/10 (+1.0)

**提升**: 暗色模式 + 系统偏好自动跟随 + 主题切换按钮。E2E 测试基础设施。
**保持**: PWA + CloudBase + localStorage 安全网 + .tcbignore。
**待做**: CI/CD 自动化部署（GitHub Actions）。
