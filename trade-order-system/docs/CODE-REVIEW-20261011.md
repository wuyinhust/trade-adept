# 通用外贸订单系统：代码审查与修复记录

日期：2026-10-11。目标：理解 Grandware 原始需求和实现，把它作为通用产品的第一个客户模板，并修复明确的数据损坏、权限和协作保存缺口。需求基线见 [产品需求 v1](通用外贸订单系统-产品需求-v1.md)，运行与验证见 [本地交付与验证](本地交付与验证-20261011.md)。

## 1. 结论及证据边界

原项目已具备订单、客户、工厂、出运、Excel 和利润页面，但其身份与数据授权主要在浏览器完成，CloudBase 使用追加整库副本与合并，不能满足可靠的多租户隔离或多人防覆盖。Grandware 品牌、四法人、团队、账号及财务逻辑与通用业务混在一起。应保留已验证业务流程，以可信业务 API 和可配置客户模板逐步替换，而不是只换品牌后作为通用 SaaS 发布。

本轮完成一套可运行的本地 SQLite 业务 API 和前端接入，修复关键业务缺陷；尚未完成完整商业产品。可编辑电子表格、通用金额模型、企业/云 SQL 驱动、付款账本、配置管理页面和正式计费仍需后续开发。线上权限或部署未改动，旧线上风险不能因本地修复而视为消除。

| 优先级 | 缺陷/业务影响                                                       | 本轮状态与代码定位                                                                                                                                                 |

| P0     | 伪造浏览器管理员会话、公开哈希重放、匿名整包访问                    | 新默认入口仅用 `server/store.py` 会话与授权，`auth.js` 不保留账号凭据；旧 `cloudfunctions/customLogin` 为历史实现，未作为新 API 使用，线上需单独迁移并轮换公开凭据 |

新增服务只允许静态运行资源，拒绝配置、口令文件、数据库、云函数、文档、测试、目录与路径穿越。当前工作区在 SMB 共享盘，SQLite 与口令存到独立私有 APFS 目录；不能将 chmod 在网络卷上的缓存表现当作权限或 SQLite 锁可靠性证明。

本轮业务记录仍保存为每租户 JSON 列，并在 SQLite 事务内更新；客户端字段补丁不等于已实现逐记录关系表。整租户版本与全量快照会增加大数据量下的写入、读取和存储成本。后续企业数据库阶段需明确关系表、索引、逐记录版本、分页查询和快照保留策略，并通过实际数据规模测试。

法人财务配置当前选择 CNY/USD 与 `grandware-v40` 策略；其他策略/结算币种的财务输入修改由服务端拒绝。通用任意币种、税务规则及公式计算仍属下一阶段。

## 4. Grandware 兼容裁决

1. 四公司是 Grandware 租户内的法人，不是产品的四个租户；固定 CO-xx 仅作为历史标识保留。第二客户使用 EX-01，配有虚构客户、供应商与订单，验证模板不依赖四公司 ID。
2. 原 PDF 只让管理员/财务看利润，经理/业务员默认隐藏；新模板采用此规则。Grandware 若需要例外，配置明确能力，不靠角色字符串偶然放行。
3. 工厂在已有法人授权范围内共享读取，写入/删除仍按 self/team/tenant 范围。共享读不授予银行或成本权限，也不允许穿透其他租户和法人。
4. “自己创建始终可见”不得穿透主体硬边界。未知归属历史需管理员核对；本轮没有猜测业务归属。
5. 线上 v40 国内 freightCostUSD/otherCostUSD 实际表示 RMB，insuranceCostUSD 表示退税百分比；名称不代表单位。归档历史全部保留，新财务修改按配置策略解释。规范金额与税率字段迁移须先由财务对账确认。

## 5. 开发顺序与收费建议

下一阶段先完成 Grandware 的付款流水、业务筛选/港口校验、金额/汇率新模型与迁移预览，再开发可编辑表格及配置管理 UI，最后接入选定的 PostgreSQL/企业数据库并做生产部署验收。每阶段用两个客户、多个法人、直接 API 越权与并发保存验证；不能靠单个演示截图证明通用化。

建议企业基础订阅费+编辑席位+企业部署/集成服务；基础隔离、冲突保护与备份不作为付费锁。团队版 ¥299/月含 5 编辑席位、协作版 ¥699/月含 15 席位，均为年付折算；企业版定制。这些为待验证试价，不是已售产品或行情结论。参考 [monday.com 官方定价](https://monday.com/pricing) 的席位和套餐结构，具体假设见产品需求第 8 节。

本轮未接入生产数据库、未修改线上权限、未部署，也未启用订阅收费。完成的本地功能、自动化结果和浏览器验收以独立验证记录为准。
