# Tradept 0.2.0 单系统版本

日期：2026-10-12。当前均为测试环境。用户要求保留并行版本，并在 main 合并为一个通用系统，Grandware 通过配置使用该产品。

## 业务行为

用户继续使用 Tradept 的现有界面和 logo。账号、公司、客户、供应商、正式订单与收付款由同一 Frappe/ERPNext 数据库维护。管理员后台是该系统的原生管理入口。工作台网关只有固定站点路由和会话签名，不存储另一份业务数据库，也不再启动同步队列。

新业务先保存待完善订单，真实商品、供应商、数量和价格齐备后建立原生 SO/PO，提交及收款使用原生流程。历史 Excel 记录保留来源 ID、金额和关联，明确作为历史参考；缺失的 SKU、汇率、创建人和逐笔账务不被推造。

ERPNext 核心可以按业务需要修改。本轮采用独立 `tradept_core` 扩展处理外贸流程与历史兼容，方便升级原生系统。电话号码保留历史原文和标准渠道的区分；标准渠道校正后以原生有效值为准，来源原文仍保留。账号默认配置开通；可选原生注册不会自行授予公司或业务权限。

## 实现边界

本版本提供数据库工作台、Excel 导入导出、外贸生产/物流扩展和原生业务复用。工作台正式销售目前使用 USD，采购与结算适配 CNY/USD；其他币种可使用原生 ERP 能力，工作台适配仍需独立验收。完整单元格协作编辑器、任意已有数据库的直接适配、自动银行对账、订阅收费和完整税务流程继续按通用需求文档迭代，不能从本次迁移或样例业务推断已完成。

Grandware历史资料及原生管理台可用；四家公司保留既有币种和原生科目，未推造历史商品或银行科目。企业真实SKU、银行及会计配置仍需提供并验证；本轮正式财务流程实际验收使用独立虚构USD主体，没有银行转账。
