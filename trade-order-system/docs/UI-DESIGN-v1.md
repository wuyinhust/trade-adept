# Grandware@once 界面设计规范 v1

更新日期：2026-10-11。根据本轮用户指令，重新处理完整需求文档 3.11 的界面要求，并直接用于现有系统的界面开发。原 PDF 保留为历史需求来源。

## 1. 设计方向

采用明亮、克制、清晰的企业工作台：参考 Apple.com 的文字层级、留白和蓝色操作表达，以及 Apple Materials 对导航层与内容层的区分。毛玻璃集中用于侧边导航、顶部导航和浮层；订单、表单和财务数据使用稳定、清晰的内容表面。

“美国科技公司风格”落实为：少量强调色、统一线性图标、明确的主次操作、紧凑有序的数据表、流畅而短促的反馈。所有业务页面以完成工作为目的，正文、金额和状态比装饰更显眼。

参考：

- Apple 美国官网：https://www.apple.com/
- Apple Materials：https://developer.apple.com/design/human-interface-guidelines/materials
- Apple Meet Liquid Glass：https://developer.apple.com/videos/play/wwdc2025/219/

这是对参考的产品化解释；本系统使用 Web 的透明度与背景模糊实现材质，不声称复刻原生 Liquid Glass 的光学效果。

## 3. 全局视觉规范

### 3.1 色彩与材质

| Token      | 浅色               | 暗色                  | 用途                 |
| ---------- | ------------------ | --------------------- | -------------------- |
| 页面背景   | #f5f5f7            | #151619               | 工作台背景           |
| 内容表面   | #ffffff            | #202226               | 表格、表单、图表面板 |
| 主文字     | #1d1d1f            | #f5f5f7               | 标题、业务信息、金额 |
| 次文字     | #6e6e73            | #a9abb3               | 日期、标签、说明     |
| 主操作     | #0071e3            | #2997ff               | 新建、提交、选中状态 |
| 成功       | #24834c            | #66ce8a               | 已完成、已收款等     |
| 待处理     | #9b6500            | #e4b65b               | 待出运、待付款等     |
| 错误／危险 | #c13f36            | #ff8d86               | 失败、删除、已取消   |
| 分隔线     | rgba(29,29,31,.08) | rgba(255,255,255,.10) | 低对比边界           |

状态必须有文字，不能只靠颜色。深浅主题都必须维持表格、菜单、浮层与图表的可读性。初次访问默认浅色，已保存的主题偏好继续生效。

### 3.2 字体与数字

- 使用系统字体：-apple-system、BlinkMacSystemFont、Segoe UI、中文系统字体回退；不依赖远程字体。
- 正文 14px，紧凑表格 12–13px，辅助说明 11–12px；品牌字距标注、状态标签及图表刻度可用 10–11px，状态仍须有完整文字。
- 页面内容标题 28px / 600；顶栏位置标题 15px / 500；指标金额 28–34px / 600。
- 金额使用等宽数字，列右对齐，清楚显示 USD、CNY 或相应币种符号。
- 标题与金额只在必要处加粗，避免每一行都争夺注意力。

### 3.3 布局与组件

- 桌面侧栏约 224px；顶栏 64px；内容左右留白 28–32px；桌面内容宽度有上限。
- 以 4px 为间距基础，常用 8、12、16、24、32px。
- 导航使用单色线性图标；图标表达功能，文字承担准确命名。
- 内容面板约 16–20px 圆角；次级块与控件 8–12px。面板阴影仅提供轻度层次。
- 主按钮 40px 高；普通按钮 36–40px；表格动作至少 30px，触屏上的有效目标至少 44px。
- 不可点击的统计信息没有抬升动效。可点击元素具有 hover、focus、active、disabled 状态。
- 交互动效 140–220ms；尊重减少动态效果偏好。

## 4. 页面信息架构

### 4.1 应用框架

左侧：文字品牌 → 工作区导航 → 系统设置 → 主题与存储状态 → 当前公司汇率。顶栏：当前位置 → 当前公司 → 全局搜索 → 用户信息。

公司选择器表示当前账套。管理员／财务的列表如果按照既有权限显示跨公司数据，页面须明确提示“全部公司数据”，避免用户误认为列表已按所选公司过滤。本轮只说明已有数据范围，不调整权限算法。

技术诊断、环境 ID 和云函数配置保留在系统设置内；主要工作流不展示云服务采购或实现细节。

### 4.2 总览

1. 页面标题、数据范围和新建订单入口。
2. 核心指标：订单数、营收、按权限显示的利润或客户／待出运数。
3. 工作进度：待出运数、待收款、按权限显示的待付货款；点击进入对应列表。
4. 近期出运：操作单号、客户、出运日期、航线、状态，优先于图表。
5. 营收趋势与订单状态分布；图表带清晰单位与可读标签。
6. 收款／工厂付款进度使用实际金额计算；没有数据时展示真实空状态，禁止固定百分比。

订单状态、出运状态、收款状态分别呈现，避免混为一条生命周期或伪造“同比增长”。

### 4.3 订单列表与详情

- 列表顶端解释数据范围，搜索和筛选组成同一工具栏；导入导出是次操作，新建是主操作。
- 表格有安静表头、行分隔线、清楚的操作单号和状态；金额右对齐。
- 列多时只让表格容器横向滚动，主页面与顶栏不横向溢出。
- 保留多选、批量修改、批量删除及原有权限限制；选中后的批量操作区明确显示数量。
- 详情先显示订单身份与主要金额，然后是业务资料、工厂、财务和物流信息。
- 编辑、新建表单保留原字段与保存动作；视觉按基本信息、工厂信息、结算、出运分组。

### 4.4 客户与工厂

- 使用与订单一致的列表、搜索和操作规范。
- 客户详情突出公司与主要联系人，联系资料和关联订单分区呈现。
- 多联系人、多工厂使用清楚的重复字段组，新增与删除组的操作具有准确标签。
- 工厂详情突出联系人、产品类别和关联订单；敏感资料按既有授权范围显示。

### 4.5 物流单证

- 先显示待出运／已出运统计，再显示出运记录。
- 操作单号与发票号码可区分，航线、日期、报关与出运状态分列。
- 详情保留时间线和关联订单入口，待完成节点不显示为已完成。

### 4.6 利润分析

- 筛选 → 四项财务指标 → 图表 → 明细表。
- 国内与香港公司的金额单位遵循业务定义，不用同一个币种标签掩盖混合口径。
- 正负金额、图例、坐标和无数据状态在两种主题中都清楚。
- 本轮沿用既有授权判断；原需求与当前权限实现的差异归入后续账号／数据权限改造。
- 本轮总览已分开呈现 CNY／USD；原利润分析页仍沿用旧汇总逻辑，跨公司混合币种须在后续业务重构修正。该条是完整设计目标，不能视为本轮已完成的计算验收。

### 4.7 设置

- 汇率、存储连接、数据可见性、数据管理、权限说明分别组织。
- 高级配置折叠呈现，危险操作使用明确文案与独立确认步骤。
- 本地预览标识与线上云端保存标识必须不同；只在得到真实回执后显示成功。

### 4.8 登录

保留 Grandware@once 与 “Welcome Back Grandware Family!”。欢迎区与登录表单形成稳定层级，用户可直接识别账号、密码和登录按钮。保留团队照片作为辅助内容，不展示测试账号或密码。

## 5. 状态、可访问性与响应式

- 表格搜索无结果、初始无数据、加载中、加载失败分别显示准确文案。
- 必填字段有标签；焦点清楚可见；按钮和筛选控件有可读名称。
- 弹窗具有 dialog 语义，焦点进入弹窗并受约束；关闭后返回触发位置。点击遮罩不关闭。
- 1024px 及以下采用抽屉导航；768px 以下主区单列，表单字段按可用宽度重排。
- 375px 下主页面无横向溢出；数据表可以在自己的容器内滚动。
- 允许浏览器缩放，保留键盘操作；暗色主题及减少动态效果均有对应行为。

## 6. 本轮实施与验收

直接修改现有应用框架、通用视觉组件、总览布局和图表呈现；所有原有业务页面采用同一规范。原始源码 ZIP 与 PDF 保留，线上数据库不通过本轮界面验证写入。

验收：本地示例环境检查七个页面、订单新建／编辑弹窗、搜索与筛选、角色切换、浅色／暗色、移动端抽屉与表单。界面检查与原有测试分别记录；不把视觉测试当作权限或线上业务验收。
