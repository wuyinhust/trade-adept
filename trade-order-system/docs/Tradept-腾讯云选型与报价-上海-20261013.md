# Tradept 腾讯云选型与报价：上海小型企业

**小企业先评估轻量应用服务器活动套餐，不必直接采用数千元的 CVM 方案。** 优先考虑 2 核 4 GB 做业务验收；用户提出的 2 核 2 GB、99 元／年套餐可作为低成本验证候选，但目前没有 Tradept 整套服务在 2 GB 内存下通过验收的证据。

腾讯云官方活动导航确有 2 核 2 GB、4 Mbps、99 元／年的宣传；具体轻量商品、上海库存、企业账号资格、磁盘大小和续费规则，应以活动购买页确认。下方 TCCLI 报价是普通询价结果，没有覆盖这些促销权益，不能当作最低采购成本。[官方活动入口](https://cloud.tencent.com/act/pro/searchall)

起步使用套餐自带 SSD，不默认加购 100 GB 数据盘；先复用企业域名和邮箱，保留服务器外备份。若能买到 99 元套餐，沿用本文普通 `.com` 首年 83 元及轻量对象存储年包 122.98 元作示例，首年合计约 **305 元**；已有域名约 **222 元**。这是条件预算，不是该企业账号已确认可下单的报价。

2 GB 的内存风险来自 ERPNext、MariaDB、Redis 与后台任务同时运行，不能只以网页打开作为验收。用预构建镜像部署，核对磁盘余量，测试多人保存、导入、财务报表、备份和重启；实测不足时再升级到 4 GB 或 8 GB。4 GB 同样是起步建议，不是已验证的容量承诺。

报价日期：2026-10-13。服务器、磁盘、域名价格已通过 **TCCLI** 查询，单位为人民币。报价使用当前账号，企业自己的折扣、购买时库存及价格可能不同；服务器续费需要重新询价。本次只做评估，未创建或购买资源。

## 1. 这份方案适合谁

按一家小企业、约 10–30 名员工、通常 3–10 人同时使用估算。主要处理订单、客户、供应商、收付款和附件，不运行本地大模型。这是容量规划假设，尚未经过这些人数的压力测试。

一台服务器运行 Tradept、ERPNext、数据库、Redis 和后台任务。选择 Ubuntu 24.04 LTS、x86_64；数据库和附件存到持久目录或卷，每天备份到服务器外；低成本方案可先用自带系统盘，独立数据盘是可选项。

本方案是企业账号内的独立云服务器，硬件由云厂商提供；不是购买整台独占物理服务器。若企业要求完全不开放公网，需要另外设计公司 VPN／专线接入，费用不在下表内。

**什么时候选 CVM：** 与现有部署指南一致，能直接放入企业自己的 VPC，后续增加服务器或拆分数据库更方便。轻量适合低负载的小企业；需要接入既有企业网络时，先核对其互联限制。[轻量使用限制](https://cloud.tencent.com/document/product/1207/44376)

轻量套餐本身的价格分别是 **230 元／月、2,346 元／年**和 **325 元／月、3,315 元／年**。表格额外加了 100 GB 独立 SSD 数据盘：100 元／月、996 元／年，方便把业务数据与操作系统分开；这项可以不买，不买时年费分别减少 996 元。不要把套餐自带系统盘误认为独立数据盘。

CVM 4 核 8 GB 的年付计算：主机及两块磁盘 **3,694.85**＋带宽 **1,145.40**＝**4,840.25 元**。接口的 `InstancePrice` 已包含本次请求里的磁盘，不能再重复加一次磁盘费。

轻量流量超额会另计费。锐驰型虽标注 200 Mbps，但为峰值且不作带宽保障承诺，本方案不因这个数字优先选它。[轻量套餐与带宽说明](https://cloud.tencent.com/document/product/1207/44755)

## 3. 还需要哪些服务

| 服务 | 选择 | 费用与处理方式 |
|---|---|---|
| 服务器外备份 | 腾讯云 COS 标准存储，私有桶；按约 100 GB 留存量规划 | **先留 20 元／月、240 元／年预算**；这是存储、少量请求及恢复下载的预算，非 API 固定报价，按实际用量结算 |
| 域名 | 优先复用企业域名的 `trade` 子域名 | 不新增域名注册费；新注册普通 `.com` 本次报价首年 **83 元**，续费 **90 元／年**；`.cn` 为 **33／38 元** |
| DNS | 已有解析服务，或 DNSPod 免费版 | 免费版起步，已有付费套餐按企业现有账单处理 |
| HTTPS 证书 | Let's Encrypt 免费证书，配置自动续期 | 证书费 **0 元**；部署人员负责续期与到期告警 |
| 发信邮箱 | 企业已有邮箱的 SMTP | 先核对是否允许系统发信及额度；新购邮箱、邮件发送服务另计 |
| 运维告警 | CPU、内存、磁盘、备份失败、证书到期 | 先用基础监控及现有通知渠道；付费日志、短信、电话另计 |

域名价格仅针对普通后缀标准注册，不表示某个名字可注册，也不包括精品域名。备份费用请在 [COS 计价器](https://buy.cloud.tencent.com/price/cos) 按企业实际用量复核。DNS 与证书参考：[DNSPod 免费版说明](https://cloud.tencent.com/document/product/302/105419)、[Let's Encrypt](https://letsencrypt.org/)。

**更便宜的备份选项：** 轻量对象存储大陆通用套餐，100 GB 容量＋每月 10 GB 外网下载，官方报价 10.58 元／月、122.98 元／年，上海适用。这是官网价，未通过 TCCLI 询到；它缺少普通 COS 的版本控制和生命周期等能力，备份轮换需脚本完成，不能混用两种产品的资源包。[价格](https://cloud.tencent.com/document/product/1207/88189) · [功能区别](https://cloud.tencent.com/document/product/1207/108904)

**首期不用另买**云数据库、托管 Redis、TKE、CLB、NAT 网关或 CDN。当前部署包自带 MariaDB、Redis 和后台任务；云数据库替换必须先验证兼容性，不应直接买 MySQL 当作替代。

已有域名可减 83 元。上表包含独立数据盘；不含人工运维、Kimi 订阅／API、新邮箱、VPN／专线、超额流量、付费日志和额外快照。备份超过 100 GB 时需要增加预算。

这四种方案都是单机：故障时可能停机，需要恢复备份。16 GB 内存提升容量，不能实现自动故障切换。企业若要求故障不中断，应另做多节点和数据库高可用方案，不能沿用本表预算。

## 5. 交给采购和 Kimi 的要求

1. 用企业实名认证账号购买，地域固定为 **上海 `ap-shanghai`**。CVM 本次按上海二区 `ap-shanghai-2` 查询，购买时再检查库存。
2. 先核对轻量活动套餐；2 GB 作为验证候选，4 GB 作为更宽裕的起步候选。需要企业 VPC 或验证后确需更多资源，再考虑表中 CVM。操作系统选择 Ubuntu 24.04 LTS x86_64，暂不购买 GPU 和额外云数据库。
3. 先使用套餐自带盘并检查剩余空间，明确数据库、附件和 Docker 持久卷路径。若额外购买数据盘，确认挂载及实际数据落盘位置；无论哪种方式，都要备份到服务器外。
4. 申请企业网址并完成适用的备案手续。上海公网网站上线前处理备案；月付价仅用于比较，办理备案需满足云资源购买时长等要求。[备案资源要求](https://cloud.tencent.com/document/product/243/18908)
5. 按 [企业私有部署指南](Tradept-企业私有部署指南.md) 安装已验收的正式版本。报价适用于当前 ERPNext 架构和新财务／邮箱功能的资源规划，不代表候选功能已发布。
6. 每天生成数据库及附件备份，包含恢复所需的站点配置与加密密钥，上传到私有存储桶。按实际大小设置保留份数，上线前在隔离环境完整恢复一次。
7. 用企业真实订单、财务报表、多人保存及批量导入验收。内存经常不足或任务积压时再扩容；8 GB 能否长期使用以这次验收为准。

## 6. 让 Kimi 重新询价

TCCLI 的安装和账号配置见 [部署指南](Tradept-企业私有部署指南.md)。下面都是只读查询，不会下单。

### 推荐 CVM：查年付总价

```sh
tccli cvm InquiryPriceRunInstances \
  --region ap-shanghai \
  --Placement '{"Zone":"ap-shanghai-2"}' \
  --ImageId img-mmytdhbn \
  --InstanceChargeType PREPAID \
  --InstanceChargePrepaid '{"Period":12}' \
  --InstanceType SA9.LARGE8 \
  --SystemDisk '{"DiskType":"CLOUD_SSD","DiskSize":60}' \
  --DataDisks '[{"DiskType":"CLOUD_SSD","DiskSize":100}]' \
  --InternetAccessible '{"InternetChargeType":"BANDWIDTH_PREPAID","InternetMaxBandwidthOut":5,"PublicIpAssigned":true}' \
  --InstanceCount 1
```

总价＝`Price.InstancePrice.DiscountPrice`＋`Price.BandwidthPrice.DiscountPrice`。查月付改 `Period` 为 `1`；查 16 GB 改实例型号为 `SA9.LARGE16`。镜像 ID 为本次查询时上海的 Ubuntu 24.04 LTS 镜像，购买当天应再核对。

### 轻量：分别查套餐与独立数据盘

```sh
tccli lighthouse InquirePriceCreateInstances \
  --region ap-shanghai \
  --BundleId bundle_gen_mc_lg8_01 \
  --InstanceChargePrepaid '{"Period":12}' \
  --InstanceCount 1

tccli lighthouse InquirePriceCreateDisks \
  --region ap-shanghai \
  --DiskSize 100 --DiskType CLOUD_SSD \
  --DiskChargePrepaid '{"Period":12}' --DiskCount 1
```

两项折后价相加才是本文轻量方案总价。16 GB 套餐 ID 改为 `bundle_gen_mc_lg16_01`。

### 域名：查首年与续费

```sh
tccli domain DescribeDomainPriceList \
  --region ap-shanghai \
  --TldList '[".com",".cn"]' \
  --Year '[1]' --Operation '["new","renew"]'
```

读取 `RealPrice`；`new` 是新注册，`renew` 是续费。原始询价 JSON、参数、时间和 RequestId 随文档包保存在 `腾讯云询价-上海-20261013` 目录，便于复核。
