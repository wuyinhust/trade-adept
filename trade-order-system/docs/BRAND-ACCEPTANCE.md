## 界面适配

- 侧栏使用原完整 logo，品牌入口返回总览；`brand-caption` 保留为登录后的企业名称。`.logo-text` 选择器仍保留，避免影响既有壳层样式。
- 登录页的 `h1` 使用同一 logo，图片 `alt="Tradept"` 提供可访问名称。登录表单及所有原有 DOM ID 保持。
- 侧栏品牌底座宽度为 180px，登录页为 230px，均受 `max-width: 100%` 限制。暗色主题使用浅色底座，让原图的深蓝文字清晰显示，原图片保持不变。
- 主色从原蓝色小幅调整到 `#185cf4`，与品牌的蓝色一致。暗色的可读性主色、成功/警告/危险语义色、表格和卡片布局保持。
- favicon、Apple Touch Icon、Web App Manifest 指向原图标。Manifest 使用 `purpose: "any"`；原图没有专门为 maskable 安全区设计，因此不声明 maskable。

## 浏览器验收项

静态检查无法替代视觉验收。以下项目由本轮主任务在本地预览核验，并记录于发布验收文档：

1. Grandware 和示例企业的租户名称均与产品 logo 并列展示，登录后不会将租户名称当作产品品牌。
2. 浅色和暗色侧栏、登录页 logo 清晰，无裁字、拉伸或遮挡。
3. 桌面侧栏及不超过 1024px 的移动菜单中，品牌不会挤压关闭按钮；小屏登录表单可用。
4. 浏览器 favicon、Manifest 和图标静态请求成功。

动态标题和工作区文案由 `js/app.js` 与 `js/backend-bootstrap.js` 的主任务实现；本文件记录品牌素材与静态页面的变更边界。
