# Tradept 版本规则

采用 `大.中.小` 三个整数，例如 `0.11.234`。Git 标签为 `v0.11.234`。不强制补零。

- 大：不兼容的产品架构、数据迁移或接口变更，后两段归零。
- 中：新增业务能力或一个可验收的功能阶段，小段归零。
- 小：兼容的缺陷修复、视觉细节及小幅优化。

Tradept 通用产品首个正式开发版本是 `0.1.0`。历史 Grandware v40、原 ZIP v56、界面资源 v57/v58 是旧系统的历史标记，不转成 Tradept 产品版本。Git 中保留 `original-zip` 和 `current-20261011` 用于追溯。

`package.json` 为版本来源；`python3 scripts/version.py 0.1.1` 同步 package-lock 与入口资源缓存参数；`python3 scripts/version.py` 检查一致性。发布须补 CHANGELOG、双需求验收记录、真实测试结果，确认发布快照不含客户导出、数据库、运行凭据或依赖目录，再创建对应不可移动的 Git 标签。

Git 源码发布、本地验证、云端部署是三个独立结果。Git 发布不代表已部署生产系统；数据库迁移也不应随源码推送自动执行。
