# Tradept 部署信息与交接表

请填写后与《Tradept 企业私有部署指南》《Tradept Kimi 部署附录》一起交给部署人员。**本表不填写密码、SecretKey、SSH 私钥内容、激活链接或数据库导出。**

## 部署前填写

| 项目 | 企业填写 |
|---|---|
| 企业名称 | 待填写 |
| 云资源归属账号／企业 | 待填写 |
| 采购方案与预算 | 上海；优先轻量活动套餐，配置及容量验收待确认；填写最终订单价、续费规则和备份预算 |
| 实例 ID、地域、可用区 | 待填写 |
| 公网 IP | 待填写 |
| SSH 用户名 | 待填写 |
| SSH 私钥在部署人员电脑上的路径 | 待填写，仅路径 |
| 企业 HTTPS 网址 | 待填写 |
| 域名 DNS 管理服务商 | 待填写 |
| 员工访问范围 | 公网／公司固定 IP／VPN，选择一种 |
| 大陆公网域名备案状态 | 已完成／办理中／不适用 |
| 法人公司名称、国家／地区、本位币 | 每家公司分别填写 |
| 管理员姓名与真实邮箱 | 可在首次初始化时补齐 |
| 邮箱准入模式及名单 | 域名白名单／指定邮箱／任意域名；仍需邀请 |
| SMTP 地址、端口、TLS 方式、发件邮箱 | 可在首次初始化时补齐，密码单独输入 |
| 运维负责人和联系渠道 | 待填写 |
