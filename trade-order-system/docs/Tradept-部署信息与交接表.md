# Tradept 部署信息与交接表

返回 [guide](guide.md)。由 AI 边部署边填写，只在缺少企业资料时询问主人。本表不记录密码、SecretKey、私钥内容、激活链接或数据库数据。

## 部署前选择

| 项目 | 企业实际选择 |
|---|---|
| 企业名称／云资源归属账号 | 待填写 |
| logo 选择及原始素材位置 | 保留 Tradept／替换企业 logo；替换时填写原图路径 |
| 已有服务器 | 没有／已有，填写授权使用的服务器 |
| 域名方式 | 已有域名的子域名／低价域名／普通 .com 等 |
| 完整域名、可注册查询时间和结果 | 待填写；已有域名填写持有状态 |
| 域名首年费用、续费价、自动续费选择 | 待填写，不填宣传预算 |
| 服务器位置 | 大陆／首尔／雅加达／曼谷／香港／新加坡／已有服务器 |
| 服务器档位 | 够用就好／推荐配置；填写实际 CPU、内存、SSD |
| 服务器地域标识、套餐／镜像 ID、架构 | 待填写 |
| 带宽、每月流量、超额计费规则 | 待填写 |
| 购买期限、实际总价、续费规则 | 待填写，云备份等单独列价 |
| 备份选择 | 私有云存储／电脑／明确不备份 |
| 电脑备份接收设备、目录、下载频率 | 选择电脑时填写 |
| 私有管理员用户名 | 待填写；主人自选或自动生成，不填密码 |
| 管理员凭据的私有输入／交付位置 | 企业密码库条目或受限文件路径 |
| 登录方式 | 账号／邮箱不验证／邮箱且验证，按正式版本能力填写 |
| 邮箱范围与真实管理员邮箱 | 选择邮箱登录时填写 |
| SMTP 地址、端口、TLS、发件地址 | 需要邮件功能时填写，密码另行输入 |
| 法人公司、国家／地区、本位币 | 每家公司分别填写 |
| 员工访问范围 | 公网／公司 IP／VPN |
| 运维负责人和联系渠道 | 待填写 |
