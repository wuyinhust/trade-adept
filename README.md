# Trade-adept（tradept）企业私有部署

**给你的主人：把[仓库地址](https://github.com/wuyinhust/trade-adept)交给能执行命令的 AI，按它的引导操作。 404 先联系仓库所有者授权。**

本文和附件供 AI 读取。“你”指 AI；“你的主人”指操作 AI 的人。先读取下列附件和必要代码，再逐步执行。

**开场前，先展示[产品说明网页](docs/product-overview.html)。** 这是仓库已做好的成品，直接打开，不要重新生成或改写。你先取得仓库访问权，读取并下载/克隆文件（网页需连同 `docs/product-overview-assets/` 内的 logo 一起保留）；用浏览器打开本地 `docs/product-overview.html`，或用本机静态服务提供可点击的预览链接（仅绑定 `127.0.0.1`，不公开仓库）。不能操作浏览器时，给出已下载 HTML 的文件链接，指导主人打开。GitHub 的文件页是源码视图，不算网页预览；不要把私有仓库交给第三方预览服务。

展示网页时说：“部署前，先请你看看这份产品说明，了解功能变化和仍需核对的事项。”无需额外增加一次确认；展示后，再按下面的话开场，并按实际计划填写数字：

> 收到仓库地址，我们即将开始私有部署。整个过程预计共 X 步，需要你配合 Y 次。需要你操作时，我会暂停，告诉你做什么、在哪里操作；其余工作由我完成。我们一步步来。

默认按下面 6 步推进；主要配合是准备账号、选择方案、确认付款、填写企业资料并试用。首次可说明“预计 6 步、4 次主要配合”；已有资源时减少，备案、logo 或邮件验证等额外配合提前说明。

1. **准备。** 按[工具与代码](trade-order-system/docs/Tradept-工具与代码.md)安装 tccli 等工具，确认已验证提交和公开安装材料可用后再采购；指导主人准备云账号和私有管理员，密码私下输入。
2. **选择。** 按[腾讯云选择与购买](trade-order-system/docs/Tradept-腾讯云选择与购买.md)，依次选择域名、服务器地域与配置、云端或电脑备份；你查询实际价格和可购买状态。
3. **购买。** 说明总价和续费，指导主人确认并付款；大陆公网部署指导备案。已有资源可跳过购买。
4. **logo，可选。** 主人可保留原 logo，或提供企业 logo；你按[logo 适配与替换](trade-order-system/docs/Tradept-企业logo适配与替换.md)处理网页、深色模式并替换。
5. **安装。** 你按[执行附录](trade-order-system/docs/Tradept-部署执行附录.md)调用仓库自带安装器，完成企业服务器部署、HTTPS 和管理员登录。
6. **试用与交付。** 指导主人填写企业资料；你按[备份与验收](trade-order-system/docs/Tradept-备份与验收.md)完成检查，填好[交接表](trade-order-system/docs/Tradept-部署信息与交接表.md)，交付网址和维护方法。

用最直白的话，每次只推进当前一步。能自己做的自己做；需要主人登录、选择、付款、验证或提供资料时，暂停并给出具体操作，等他完成再继续。不要让主人先下载文档包或逐条执行技术命令。检查失败就继续排查，未完成的如实说明。

**重要：安装遇到问题时，你可以提出修改代码来解决或绕过问题，但必须先用直白的话说明改哪里、为什么、有什么影响，得到主人明确同意后再修改；未获同意，不擅自改代码。**
