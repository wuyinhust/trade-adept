# 外贸订单系统本地预览

启动后访问 http://127.0.0.1:3086 。默认使用已导入的线上业务快照；未导入时使用示例数据。

```sh
python3 local-preview/server.py
```

在 `AI 外贸` 工作区执行上述命令；默认只监听本机地址。

- `trade-order-system/` 是当前开发源码目录，界面已按 `docs/UI-DESIGN-v1.md` 更新。下载目录中的原始 ZIP 保留。
- `local-preview/` 是独立预览启动层。服务器只在提供 HTML 时替换应用入口。
- 页面懒加载路径已在应用源码中修正。
- 初次打开自动进入管理员角色；右下角可以切换所有原有用户角色。
- 当前数据源是 2026-10-11 20:37（北京时间）从线上系统“导出全部数据 (JSON)”下载的 `app_data / gw_data` 业务快照。预览修改保存在当前浏览器的 localStorage 中。
- 每份快照使用按文件 SHA-256 区分的浏览器存储和备份键，旧示例数据及其本地修改不会混入新快照。
- CloudBase、云函数和外部汇率请求已隔离；图表和 Excel 库使用源码指定版本的本地副本。
- 线上快照模式关闭自动汇率刷新，保留导出的汇率；手动设置汇率仍仅修改本地工作副本。
- “恢复线上快照”恢复当前浏览器的本地数据；原始下载文件和归档快照保持不变。
- 服务关闭后需要重新运行启动命令。本轮检查记录见 `trade-order-system/docs/UI-VALIDATION-v1.md`；云端部署脚本未执行。

