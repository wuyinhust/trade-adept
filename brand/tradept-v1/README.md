# tradept · Logo v1

面向外贸订单与团队工作区的第一版品牌标识。

## 设计

小写圆润字标提供亲和感；蓝色 t 结合青绿流线，表达连接与订单流转。深蓝字标适用于浅色背景。配色以现有网站的蓝色方向为基础。

- 蓝色设计锚点：`#2563EB`
- 青绿设计锚点：`#18BFA6`
- 深蓝设计锚点：`#172B4D`

PNG 由图像工具生成，实际像素包含轻微色彩变化；以上是后续矢量制作的参考色。

## 文件

- `tradept-logo.png`：透明背景横版 Logo，浅色网站页头、登录页使用。
- `tradept-icon.png`：透明背景独立图标，浏览器标签及应用图标使用。
- `preview.html`：品牌与导航栏尺寸预览。
- `preview.png`：预览截图。
- `prompts.md`：生成工具、模板及完整提示词。

当前交付为 PNG 设计稿。网站界面尚未替换。

## 使用

横版 Logo 建议显示宽度 140–180 px；独立图标建议 32 px 及以上。预览中也列出 16、24、32 px 的表现，可按具体界面选择。

横版 Logo 本身带有上下透明留白，放入导航栏时按整张图片的高度预留空间。不要拉伸或改变比例。
